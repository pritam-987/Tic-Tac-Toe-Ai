# 🎮 Tic Tac Toe AI

An **AI-powered Tic Tac Toe game** built using **Python and Pygame**, featuring an **unbeatable Minimax AI**, clean UI, and  **desktop (EXE)****  version.**

This project was built as a fully *shipped* project and includes source code, a standalone Windows executable.

## ⬇️ Download (Windows)

You can download the standalone Windows executable from **GitHub Releases**:

👉 Go to **Releases** → Download `TicTacToeAI.exe`

No Python installation required.

---

## ✨ Features

* Play as **X or O**
* Clean and responsive **Pygame UI**
* Unbeatable **Minimax AI**
* Proper win & tie detection
* "Play Again" restart button
* Web & desktop support

---

## 🤖 AI Details

The AI uses the **Minimax algorithm**, meaning:

* It never loses
* It always chooses the optimal move
* Best possible outcome for the player is a **draw**

This makes the AI perfect for learning and experimentation.
